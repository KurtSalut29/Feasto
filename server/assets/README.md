Files the report downloads (PDF, Word, Excel) are built with.

- `feasto-logo.png`, `feasto-mascot.png`: copies of `web/public/Logo/`.
- `fonts/Poppins-*.ttf`: Feasto's heading font. `fonts/NotoSans-*.ttf`: the body and number font (it has the ₱ sign, which Poppins doesn't).
  Both are under the SIL Open Font License 1.1, which allows bundling them with software.
