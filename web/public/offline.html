You're offline

Feasto needs an internet connection. Check your Wi-Fi or mobile data, then try again.

  1. Connect to the same Wi-Fi as the Feasto laptop, not mobile data.
  2. Check the address. It changes when the laptop moves to another Wi-Fi: scan the QR code in Admin › System on the laptop.
  3. Turn off anything that changes how the phone finds websites: on Android, Settings › Network › Private DNS › Off; on iPhone, turn off Private Relay and any VPN.
  4. Set the phone's date and time to automatic.
